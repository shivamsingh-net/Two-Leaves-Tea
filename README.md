# Two-Leaves-Tea

A fully responsive tea brand landing page, built as a front-end recreation practice project (based on the design of an existing tea company's site, built from scratch with my own HTML and CSS).

## About

This was my first project where I really focused on making something properly responsive instead of just designing for one screen size. It's a full page top to bottom — a product promo hero, a best sellers grid, a reviews section, a photo-heavy "our origins" story section, a newsletter signup, and a full multi-column footer.

## Built with

- HTML
- CSS
- Media queries for responsiveness
- CSS Grid for the layout

## Features

- Responsive layout that adapts across screen sizes using media queries
- Best sellers product grid with hover effects on each card
- Image hover/scale effects on product and review cards
- Horizontally scrollable reviews section with colorful cards
- Full-bleed background image section for the brand story
- Icon row explaining brand values (quality, sustainability, sourcing)
- Newsletter signup section
- Multi-column footer with grouped links and social icons

## Running it locally

```bash
git clone https://github.com/shivamsingh-net/Two-Leaves-Tea.git
cd Two-Leaves-Tea
```

Just open `index.html` in your browser after that. Nothing else needed.

## What I was practicing

- Writing media queries to make a long, multi-section page actually responsive
- Using CSS Grid for product and review card layouts
- Adding hover effects on images and cards for a more polished feel
- Structuring a long real-world style page (hero, product grid, reviews, story section, newsletter, footer) instead of just a single section

## Note

This project recreates the layout and design of an existing tea brand's website as a learning exercise. It's not an original brand and isn't affiliated with the real company — built purely for front-end practice.
